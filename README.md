# Strata Gallery

Every [Strata](../Strata) control on a page of its own, running on Strata's Java2D adapter. Use it to see what a control looks like, try its states, and watch the events it fires.

The gallery builds against the Strata checkout beside it at `../Strata`, so check the two out side by side. Nothing is published yet.

```bash
./gradlew :gallery:run
```
